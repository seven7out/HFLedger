              /ledger-sweep
              Refreshes state
            

            
Refresh the whole operating picture

            
Reconciles durable events, checks configured read-only observations, and refreshes the operating brief.

            

              
Use it
When you need current truth, especially before deciding what to do.

              
Guardrail
Observations never grant build, merge, deployment, or owner-interruption authority.

            

          


          

            

              /ledger-status
              Read only
            

            
Get a fast re-entry brief

            
Reads the existing board and ranks what matters now by leverage and urgency without re-pulling every source.

            

              
Use it
For a quick “where are we?” or “what should I do next?”

              
Difference
If the board is stale, run /ledger-sweep first.

            

          


          

            

              /ledger-work
              Builds
            

            
Work the safe ready queue

            
Chooses fully specified, explicitly safe work and reports bounded start, verification, and shipment evidence.

            

              
Use it
When the board contains authorized Ready-for-Build work.

              
Guardrail
Protected, ambiguous, or owner-gated work stays out.

            

          


          

            

              /ledger-attend
              You stay involved
            

            
Handle work that needs the owner

            
Presents admitted decisions and exact manual actions with their evidence, risks, and completion proof.

            

              
Use it
For protected choices or owner-only steps that autonomous work must skip.

              
Guardrail
Only admitted asks enter this lane; vague escalations are rejected.
